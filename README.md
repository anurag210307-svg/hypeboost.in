# HYPEBOOST - Influencer Marketing Agency

A neubrutalist landing and booking platform for creator and influencer marketing campaigns. Built with React 19, Vite, and Tailwind CSS.

## 🚀 Deploy to Vercel

### Option 1: Deploy with Git (Recommended)
1. Push this project to your GitHub / GitLab / Bitbucket repository.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Click **"Import Project"** and select your repository.
4. Vercel will automatically detect the settings from [vercel.json](file:///c:/Users/Anurag%20kumar/Downloads/hypeboost/vercel.json):
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
5. Click **Deploy**.

### Option 2: Deploy with Vercel CLI
1. Install the Vercel CLI globally if you haven't already:
   ```bash
   npm i -g vercel
   ```
2. Run deployment from this directory:
   ```bash
   vercel
   ```
3. To deploy to production:
   ```bash
   vercel --prod
   ```

## 💻 Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run dev server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Preview production build:**
   ```bash
   npm run preview
   ```
